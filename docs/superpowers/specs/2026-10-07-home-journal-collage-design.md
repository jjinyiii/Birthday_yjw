# 首页日记页拼贴视觉设计

## 目标

把生日首页从“照片墙 + 蛋糕卡片”提升为一页更有故事感的手帐日记页，同时保留照片、点蜡烛、页面导航和暖色调。

## 视觉方向

- 采用用户选择的 C 方案：日记页拼贴。
- 背景继续使用奶油白，文字使用木棕，粉色和燕麦色作为纸张、胶带、印章的点缀。
- 增加日期索引、手写标签、邮票/印章感的小贴纸和页面角落涂鸦。
- 四张照片保持拍立得比例与轻微随机倾斜，周围增加“记录 01/02”等小批注。
- 蛋糕互动保持原有 JavaScript，仅将卡片外观改为贴在纸页上的愿望便签。

## 响应式约束

- 桌面端保留错落布局和装饰层次。
- 560px 以下改为单列，装饰元素缩小或回到正常流，避免遮挡照片、蛋糕和按钮。
- 不新增第三方依赖，不使用霓虹、紫蓝渐变或科技感玻璃效果。

## 验证

- 检查首页四张照片、蛋糕按钮和页面导航仍可用。
- 检查视频、信件路由以及 BGM 代码未被修改。
- 在 390px 和桌面宽度检查无横向溢出。
